# Deploy SecureOne

Ready-made templates for running [SecureOne](https://secureone-website.vercel.app), sign-in, single sign-on and
access control for your applications, on hosting platforms. Each one runs the published image
`dmtavs0108/secureone` with PostgreSQL 16 and Redis. Documentation: https://secureone-website.vercel.app/docs/

When SecureOne is running, open your address followed by **/admin/setup** to finish the setup.

## Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/DTAVS0108/secureone-deploy)

Creates the SecureOne service, a Render Postgres database and a Render Key Value instance. Render asks for
`SECUREONE_PUBLIC_BASE_URL`: enter `https://<service name>.onrender.com`, or your own domain (then add it to the
service under Settings → Custom Domains).

The encryption key is generated by Render as `SECUREONE_ENCRYPTION_KEY`. Copy it from the service's Environment
page and keep it somewhere safe: without it, a database backup cannot be used.

## DigitalOcean App Platform

Uses [`digitalocean/app.yaml`](digitalocean/app.yaml) with `doctl`. The steps (two databases, an encryption key,
`doctl apps create`) are at the top of the file.

## Portainer

In Portainer, **Settings → App Templates**, set the URL to

```
https://raw.githubusercontent.com/DTAVS0108/secureone-deploy/main/portainer/templates.json
```

then choose **SecureOne** under **App Templates**. Or paste
[`portainer/docker-compose.yml`](portainer/docker-compose.yml) into **Stacks → Add stack** and set the variables
`PUBLIC_URL` and `DB_PASSWORD`.

## Unraid

[`unraid/secureone.xml`](unraid/secureone.xml). Install PostgreSQL 16 and Redis from Community Apps first, then
SecureOne, and fill in the database URL, Redis URL and an encryption key (`openssl rand -base64 32`).

## About this repository

Hosting platforms read their templates from a public Git repository, so the templates live here on their own. This
repository holds only the templates and this README: no source code and no secrets. Every template runs the
published image `dmtavs0108/secureone:0.1.0`; a new SecureOne release updates the version here.

## Before going live

- SecureOne needs an **https** address. The platforms above provide one. On Portainer and Unraid, put a reverse
  proxy with a certificate in front of the port.
- Keep the encryption key with your backups, but not in the same place as the database backup.
