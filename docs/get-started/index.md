# Get started

SecureOne is one place for sign-in, single sign-on, multi-factor authentication, users, roles and permissions for
all your applications. It speaks the standards your apps already understand (OAuth 2.1, OpenID Connect, SAML 2.0,
SCIM 2.0) and runs as a single container next to PostgreSQL and Redis.
