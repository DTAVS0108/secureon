# Documentation and the website

`docs/` is the single source for two readers:

| Where | Shows | Built by |
|---|---|---|
| Console, `/admin/documentation` | Every page the reader may see, with search | `apps/admin-web/src/lib/documentation/` (reads `docs/` at runtime) |
| Public website, `/docs/` | Pages marked `audience: public` only | `apps/website/scripts/sync-docs.mjs`, then Astro and Starlight |
| GitHub | Every file; `docs/README.md` is the index | `python scripts/docs/docs_tool.py index` |

## Spaces and pages

A top-level folder is a **space**; a folder inside it is a **section**. Each folder has an `index.md` that introduces
it and appears as its *Overview*. Every page starts with front matter:

```yaml
---
title: Deployment
summary: One line, shown in menus, cards and search
order: 2
audience: public        # public | operator | internal
---
```

| `audience` | Console | Website |
|---|---|---|
| `public` | Everyone | Published |
| `operator` | Signed-in operators; others see the page locked | Not published; links to it become plain text |
| `internal` | Platform operators only; hidden for others | Not published |

A page with a missing or unknown `audience` is treated as `internal`, so nothing is published by accident.

## Writing

- Titles have no numbers; the order comes from `order`.
- Link between pages with relative paths (`../install/deployment.md#all-settings`).
- Console addresses are paths (`/admin/documentation`); examples use `$SECUREONE_URL`. Only local development
  pages use `http://localhost:9000`.
- Panels use GitHub's syntax, rendered by the console and the website alike:

```markdown
> [!NOTE]
> Something worth knowing.
```

`[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` and `[!CAUTION]` work the same way. Diagrams: Mermaid code blocks.

## Checks

```bash
python scripts/docs/docs_tool.py check   # front matter, broken links, spaces without index.md
python scripts/docs/docs_tool.py index   # rewrite docs/README.md after adding or renaming pages
```

The API reference pages (`docs/api/` except `index.md`, `getting-started.md` and `swagger-and-openapi.md`) are
generated by `scripts/api-docs/generate_api_reference.py` from the OpenAPI document; regenerate them instead of
editing them.

## The website

```bash
pnpm --filter website dev        # http://localhost:4321, rebuilt from docs/ on start
pnpm --filter website build      # static site in apps/website/dist
docker compose -f deploy/docker-compose.website.yml up -d --build   # http://localhost:8080
```

Product pages live in `apps/website/src/pages/`; the documentation section is generated, never edited by hand.
Set `SITE_URL` to the website's public address when it moves to its own domain.
