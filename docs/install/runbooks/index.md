# Runbooks

Short, ordered procedures for the moments that matter. Each one lists what to check before you start and how to
confirm it worked.

| Runbook | When |
|---|---|
| [Deploy](deploy.md) | Installing or updating a release |
| [Rollback](rollback.md) | A new release misbehaves |
| [Incident response](incident.md) | Sign-in fails, errors rise, or something looks wrong |
| [Key rotation](key-rotation.md) | Rotating token-signing or encryption keys |
| [Custom domains](custom-domain.md) | A tenant signs in on its own domain |
